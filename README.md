## <img src="https://img.shields.io/badge/-8B5CF6?style=flat-square" width="12" height="20"/> Featured Projects

<details open>
<summary><b>&nbsp;DocMind AI &nbsp;—&nbsp; Source-Grounded Document Q&amp;A with Hallucination Control</b></summary>

<br/>

A production document Q&A platform that lets users chat with their files while a **quote-verification layer** checks every generated answer against the source, effectively neutralizing AI hallucination.

| | |
| :--- | :--- |
| **Stack** | Python · FastAPI · JavaScript · Google Gemini API · Netlify |
| **Scale** | Multi-file search with per-session document isolation |
| **Performance** | RAG retrieval pipeline for fast, context-grounded responses |
| **Security** | Per-session isolation · request rate limiting |
| **Impact** | Trustworthy answers verified line-by-line against source content |
| **Repository** | [`Live Demo`](https://your-docmind-demo.com) · [`GitHub`](https://github.com/Anandtripathiii/Docmind-AI) |

DocMind pairs a **RAG pipeline** with a novel verification step: rather than trusting the model's output, each answer is re-checked against the retrieved passages before it reaches the user — a practical solution to the trust problem in document AI.

</details>

<details>
<summary><b>&nbsp;CodePilot AI &nbsp;—&nbsp; Dual-LLM Coding Assistant with RAG</b></summary>

<br/>

A full-stack coding companion that answers questions, debugs, and explains code by orchestrating **two LLMs** in parallel, grounded in the user's own uploaded files and live documentation.

| | |
| :--- | :--- |
| **Stack** | Python · Flask · FAISS · Gemini + OpenAI APIs · Gunicorn · Render |
| **Scale** | RAG over user-uploaded files + live documentation search |
| **Performance** | FAISS vector store powering semantic code search |
| **Security** | Per-visitor session isolation · bring-your-own-key auth · prompt-safety guardrails |
| **Impact** | Context-aware debugging and explanation across two complementary models |
| **Repository** | [`Live Demo`](https://your-codepilot-demo.com) · [`GitHub`](https://github.com/Anandtripathiii/CodePilot-AI) |

CodePilot demonstrates **multi-model architecture** done safely — combining Gemini and OpenAI behind a Flask backend, with a vanilla-JS frontend, isolated sessions, and guardrails that keep the assistant on task.

</details>

<details>
<summary><b>&nbsp;NovaChart SupportAI &nbsp;—&nbsp; Prompt-Engineered Customer Support Engine</b></summary>

<br/>

An AI customer-support assistant that classifies incoming issues, resolves them, and escalates to humans when needed — engineered as a **measurable prompt pipeline**, not a single prompt.

| | |
| :--- | :--- |
| **Stack** | Python · Streamlit · Google Gemini API · Pandas |
| **Scale** | 8 distinct support scenarios with automated issue classification |
| **Performance** | 5-stage prompt pipeline with self-evaluated confidence scoring |
| **Security** | Human-escalation logic for low-confidence or sensitive cases |
| **Impact** | Benchmarked basic vs. few-shot vs. chained prompting on quality, accuracy & escalation |
| **Repository** | [`Live Demo`](https://your-novachart-demo.com) · [`GitHub`](https://github.com/Anandtripathiii/NovaChart-SupportAI) |

NovaChart treats prompt engineering as an **engineering discipline** — with a built-in testing module that benchmarks prompting strategies on hard metrics, turning "prompt tweaking" into a reproducible, evaluable pipeline.

</details>
